v17.4 관리자 학생 목록 개선

추가 기능
- 학생별 체크박스 선택
- 현재 검색 결과 전체 선택
- 선택 학생 일괄 삭제
- 선택 인원 표시
- 학생 목록 최대 높이 520px
- 학생 목록 내부 세로 스크롤
- 스크롤 중에도 표 제목 행 고정

주의
- 학생 명단에서 삭제해도 기존 submissions, evaluations, feedback 문서는 자동 삭제되지 않습니다.
- 검색 중 '현재 목록 전체 선택'을 누르면 화면에 보이는 검색 결과만 선택됩니다.

적용
1. 압축 해제
2. public 폴더를 기존 프로젝트에 병합·덮어쓰기
3. VS Code 저장
4. 커밋
5. 변경 내용 동기화
6. GitHub Actions 자동 배포 완료
7. 관리자 페이지에서 Ctrl+Shift+R

Firestore 규칙은 변경하지 않습니다.
