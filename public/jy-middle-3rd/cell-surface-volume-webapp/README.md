# 세포의 표면적과 부피 탐구 웹앱 — 1차 프로토타입

## 포함 파일
- `student/`: 학생용 탐구 웹앱
- `teacher/`: 교사용 평가 대시보드
- `common/`: 추후 Firebase 공통 모듈 위치

## 실행 방법
1. 압축을 풉니다.
2. `student/index.html`을 열어 학생용 화면을 확인합니다.
3. `teacher/index.html`을 열어 교사용 화면을 확인합니다.

## 체험용 학생 계정
- 1반 1번 / 생년월일 `20120301`
- 1반 2번 / 생년월일 `20120417`

학생용에서 제출한 자료는 같은 브라우저의 `localStorage`에 저장되며,
교사용 대시보드에서 확인할 수 있습니다.

## 현재 구현된 기능
- 휴대폰·태블릿·데스크톱 반응형 화면
- 반·번호·생년월일 8자리 로그인 체험
- 세포 한 변 길이와 침투 깊이 조절
- 표면적, 부피, 표면적/부피 비, 침투 부피 비율 자동 계산
- 최근 실험 결과 비교
- 예상·자료 해석·결론·모형 한계 작성
- 자동 임시 저장
- 제출 자료 확인
- 교사용 학생 목록, 이름 표시, 점수·피드백 저장

## 중요한 안내
이 버전은 화면과 학습 흐름을 검토하기 위한 **작동형 프로토타입**입니다.

현재 학생 명단, 로그인, 제출 자료는 브라우저 내부 저장소를 사용합니다.
실제 운영용 버전에서는 다음 작업이 추가되어야 합니다.

- Firebase Authentication 또는 Custom Token 연동
- Firestore 학생 명단·제출물 저장
- Cloud Functions 학생 로그인 검증
- 학생 이름 AES-GCM 암호화 및 교사 화면에서 서버 복호화
- 생년월일 원문 미저장, HMAC 검증값 저장
- 교사 2명 권한 설정
- Firestore Security Rules
- App Check
- CSV/엑셀 학생 명단 업로드
- 학년도 보관 및 새 학년도 생성
- AI 평가 초안 기능

## 이번 수정
- 휴대폰 교사용 화면에서 실험 결과 표를 카드형으로 표시
- 교사용 AI 피드백 초안 버튼 추가(현재는 로컬 규칙 기반 체험 기능)
- 평가 저장 시 학생에게 공개
- 학생이 재접속하면 교사 점수와 피드백 확인 가능

실제 AI 모델 연결은 Cloud Functions와 API 키 설정 후 적용해야 합니다.

## v4 화면 개선
- 실험 결과를 평가 영역 옆의 좁은 표에서 분리
- 상세 화면 상단 전체 폭에 실험별 카드로 표시
- 학생 답변과 교사 평가를 아래에서 2열 배치
- 화면이 좁아지면 자동으로 1열 전환
- 점수 입력 시 총점 즉시 계산
- AI 초안과 공개 저장 버튼의 구분을 명확하게 표시

## v5 학생 공개 정책
- 교사용 대시보드에는 영역별 점수와 총점 유지
- 학생 화면에는 점수와 루브릭 점수 비공개
- 학생에게는 교사 피드백 내용과 평가 일시만 공개
- 저장 버튼 문구를 `평가 저장·피드백 공개`로 변경

## v6 이중 평가 구조
- 1차: AI가 루브릭별 점수와 피드백 초안 생성
- AI 결과는 학생에게 공개되지 않음
- 교사는 AI 결과를 교사 평가 영역으로 복사 가능
- 2차: 교사가 점수와 피드백을 검토·수정하여 최종 확정
- 임시 저장 시 학생 비공개
- 최종 저장 시 학생에게 피드백만 공개
- 학생에게 점수는 공개하지 않음

현재 프로토타입의 AI 평가는 규칙 기반입니다. 실제 AI 모델은 Cloud Functions에서 연결해야 합니다.

## v7 수정
- AI 1차 평가가 실행되지 않던 `selectedId` 참조 오류 수정
- 선택한 학생의 실제 제출 ID를 기준으로 AI 결과 저장
- AI 1차 평가와 교사 2차 평가를 데스크톱에서 나란히 배치
- 좁은 화면에서는 자동으로 위아래 배치
- AI 결과를 교사 평가로 가져오는 기능 수정
- AI 평가 및 교사 임시 저장 시 기존 AI 결과가 사라지지 않도록 보존
- 교사 최종 저장 상태일 때만 `평가 완료`로 표시

## v8 학생 피드백 표시 위치
- 선생님의 평가와 피드백은 학생 로그인 후 첫 번째 화면에서만 표시
- 2단계 실험, 3단계 자료 해석, 4단계 결론 화면에서는 자동 숨김
- 첫 번째 화면으로 돌아오면 다시 표시


## v11 Spark 무료 요금제 버전

- Cloud Functions 사용 안 함
- Secret Manager 사용 안 함
- 교사 개인 API 키 입력·저장 기능 없음
- 외부 AI API 호출 없음
- 1차 AI 평가는 비용이 들지 않는 규칙 기반 보조 평가
- 2차 평가는 교사가 직접 검토·수정
- 학생에게는 최종 피드백만 공개
- 현재 제출·평가 자료는 같은 브라우저의 localStorage에 저장

ChatGPT Plus/Pro 등 ChatGPT 구독은 OpenAI API 사용료와 별개이므로
웹앱에서 ChatGPT 구독을 API처럼 직접 연결할 수 없습니다.
