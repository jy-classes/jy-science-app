v14 생년월일 로그인 및 기기 변경 지원

학생 로그인:
- 반
- 번호
- 생년월일 8자리
- 접속코드 사용 안 함

테스트 학생:
1반 1번 / 20120301 / 김가은
1반 2번 / 20120417 / 박나연

적용 순서:
1. public 폴더를 기존 프로젝트에 병합·덮어쓰기
2. firestore.rules의 교사 이메일 확인
3. Firebase 콘솔 > Firestore Database > 규칙에 firestore.rules 전체 붙여넣기 > 게시
4. VS Code 저장 > 커밋 > 동기화로 Hosting 자동 배포
5. 교사용 화면에 Google 로그인 한 번 실행
   - 테스트 학생 2명이 students 컬렉션에 자동 등록됨
6. 학생용 화면에서 생년월일로 로그인 후 제출
7. 교사용 평가 후 학생이 다른 기기에서도 같은 정보로 다시 로그인하여 피드백 확인

중요:
- 생년월일을 아는 사람은 해당 학생 계정을 다시 연결할 수 있습니다.
- 사용자의 요청에 따라 접속코드는 사용하지 않습니다.
- Gemini API 키와 reCAPTCHA 비밀 키는 소스에 넣지 않습니다.
